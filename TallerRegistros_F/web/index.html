💻 Guía del Taller y Código C (CMSIS Step-by-Step)

CMakeLists.txt (Configuración de Rutas y Chip) 
# =========================================================================
# 1. INCLUIR RUTAS DE CABECERAS CMSIS (target_include_directories)
# =========================================================================
target_include_directories(${PROJECT_NAME} PRIVATE
  # Ruta 1: Drivers CMSIS genéricos de ARM Cortex-M
  "/home/mgz/STM32Cube/Repository/STM32Cube_FW_F4_V1.28.3/Drivers/CMSIS/Include"

  # Ruta 2: Drivers CMSIS específicos de ST para la serie STM32F4xx
  "/home/mgz/STM32Cube/Repository/STM32Cube_FW_F4_V1.28.3/Drivers/CMSIS/Device/ST/STM32F4xx/Include"

  # Ruta 3: Cabeceras propias del proyecto en carpeta Inc/
  "${CMAKE_CURRENT_SOURCE_DIR}/Inc"
)

# =========================================================================
# 2. DEFINIR MACRO DEL MICROCONTROLADOR (target_compile_definitions)
# =========================================================================
target_compile_definitions(${PROJECT_NAME} PRIVATE
  STM32F411xE
)

⚙️ Guía de Configuración CMake Paso a Paso

  • Paso 1 - Abrir CMakeLists.txt: Abre el archivo en la raíz del proyecto VS Code.
  • Paso 2 - target_include_directories: Añade la ruta a Drivers/CMSIS/Include y a Drivers/CMSIS/Device/ST/STM32F4xx/Include para resolver los #include <stm32f4xx.h>.
  • Paso 3 - target_compile_definitions: Agrega la macro STM32F411xE. Esto le indica a los archivos CMSIS qué registros e interrupciones habilitar para el STM32F411RE.
  • Paso 4 - Reconfigurar: Presiona Ctrl + Shift + P $\rightarrow$ CMake: Configure para aplicar los cambios y limpiar errores de IntelliSense.
Src/main.c (Hola Mundo PA5) 
// 1. Habilitar reloj de GPIOA
RCC->AHB1ENR |= (1 << 0);

// 2. Configurar PA5 como Salida en MODER (bits 11:10 = 01)
GPIOA->MODER &= ~(0b11 << (5 * 2)); // Limpiar bits
GPIOA->MODER |=  (0b01 << (5 * 2)); // Asignar 01

// 3. Configurar Push-Pull y Low Speed
GPIOA->OTYPER  &= ~(1 << 5);
GPIOA->OSPEEDR &= ~(0b11 << (5 * 2));
GPIOA->PUPDR   &= ~(0b11 << (5 * 2));

// 4. Encender LED escribiendo en ODR
GPIOA->ODR |= (1 << 5);

🔍 Explicación Paso a Paso

  • Habilitar Reloj: Sin activar RCC->AHB1ENR |= (1 << 0), el puerto GPIOA se encuentra desenergizado y cualquier lectura/escritura fallará.
  • Cálculo del Desplazamiento: Cada pin ocupa 2 bits en MODER. Para el pin 5: $5 \times 2 = 10$. Desplazamos `0b01` 10 posiciones a la izquierda.
  • Máscara de Limpieza `&= ~`: Limpiamos los bits antes de escribir para asegurar que no queden valores previos ruidosos.
  • Escritura en ODR: GPIOA->ODR |= (1 << 5) coloca el bit 5 en nivel alto (3.3V), encendiendo el LED verde.
Src/main.c (Pulsador PC13) 
// 1. Habilitar reloj de GPIOA y GPIOC
RCC->AHB1ENR |= (1 << 0); // GPIOA
RCC->AHB1ENR |= (1 << 2); // GPIOC

// 2. PA5 Salida (LED LD2)
GPIOA->MODER &= ~(0b11 << (5 * 2));
GPIOA->MODER |=  (0b01 << (5 * 2));

// 3. PC13 Entrada (Pulsador B1) (bits 27:26 = 00)
GPIOC->MODER &= ~(0b11 << (13 * 2));

// 4. Bucle Principal de Lectura
while (1) {
    // Evaluamos el bit 13 en IDR (Active-Low: 0 = Presionado)
    if ((GPIOC->IDR & (1 << 13)) == 0) {
        GPIOA->ODR |= (1 << 5);  // Boton presionado -> LED encendido
    } else {
        GPIOA->ODR &= ~(1 << 5); // Boton suelto -> LED apagado
    }
}

⚡ Lógica Active-Low del Botón B1

  • Pull-up Externo: El botón B1 en la NUCLEO-F411RE tiene una resistencia que lo mantiene en 3.3V (1 lógico) en reposo.
  • Contacto a GND: Al presionar el botón, el circuito cierra a tierra (0V), leyendo un 0 lógico en GPIOC->IDR bit 13.
  • Máscara de Lectura: (GPIOC->IDR & (1 << 13)) aísla el bit 13 e ignora los demás pines de GPIOC.
